# 🫐 fuzzel 🍑

BlueberryPeach for [fuzzel](https://codeberg.org/dnkl/fuzzel).

## Installation

1. Open your `fuzzel.ini` file, found in `$XDG_CONFIG_HOME/fuzzel/` (defaulting to `$HOME/.config/fuzzel/fuzzel.ini` if `$XDG_CONFIG_HOME` is unset).
1. Remove existing `[color]` section if there is one.
1. Include the preferred file `./blueberry_peach_dark.ini` or `./blueberry_peach_light.ini` in your configuration file using `include=<path-to-your-theme-file>` in the main section scope of `fuzzel.ini`.
