# 🫐 eza 🍑

BlueberryPeach for [eza](https://github.com/eza-community/eza).

## Installation

1. Make sure eza's config directory exists. That's usually `$XDG_CONFIG_HOME/eza` (for example `~/.config/eza`).
2. Copy the `.yml` file of your chosen flavor from this directory to `theme.yml` in eza's config directory.

For more details see the [eza README on custom themes](https://github.com/eza-community/eza#custom-themes).
