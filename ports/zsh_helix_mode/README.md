# 🫐 ZSH Helix Mode 🍑

BlueberryPeach for [zsh-helix-mode](https://github.com/Multirious/zsh-helix-mode).

## Installation

Decide whether you want to use `blueberry_peach_dark` or `blueberry_peach_light`.

1. Copy the `.sh` files from this directory into a location from where you want to source them.
   - Alternatively, you can clone this repository and symlink the files.
2. Source the `.sh` file from your `~/.zshrc`.

> [!NOTE]
> Depending on your terminal emulator, you may want to ensure they don't override the cursor style.
> For ghostty, that could be (for example):
>
> ```ini
> cursor-style = block;
> cursor-style-blink = false;
> shell-integration-features = no-cursor;
> ```
